# Site Animal Pet

Página institucional para um pet shop de Campo Grande, MS. O projeto foi inspirado em um negócio real e criado como **peça de portfólio**, sem fins comerciais e sem vínculo oficial com a empresa.

🔗 **Acesse o site:** https://animalpetcg.netlify.app/

## Sobre o projeto

O objetivo foi montar uma página que apresenta o pet shop de forma clara: o que a loja oferece, onde fica e como falar com ela. A página abre com uma mensagem direta ao cliente, seguida de uma chamada para contato, pensando em quem acessa pelo celular.

## O que eu usei

- HTML, para a estrutura da página
- CSS, para o visual e a adaptação a telas de celular e computador
- Netlify, para a publicação do site

## Como foi feito

Este projeto foi desenvolvido com o apoio de ferramentas de IA (*vibe coding*). Meu papel foi definir o conceito, a organização do conteúdo e o visual, revisar o resultado e publicar o site.

## Como abrir no computador

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
